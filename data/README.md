# data：記事で使った計測データ（公開用に加工済み）

続報「冷蔵庫へのサイバー攻撃、米当局も警告へ」（2026-11-07）の3章「独自計測」で使った計測結果です。

| ファイル | 計測日時（JST） | 作成したスクリプト | クエリ数 |
|---|---|---|---:|
| `2026-11-07_exposure_count_public.json` | 2026-11-07 09:49〜09:50 | `exposure_count.py` の元になった版（記事では「第7回」） | 38 |
| `2026-11-07_surge_breakdown_public.json` | 2026-11-07 09:57〜09:58 | `surge_breakdown.py` の元になった版（記事では「第7b回」） | 39 |

ファイル内の `"round": 7`・`"round": "7b"` は、記事の計測回を表します。

## 読むときの注意

- **件数は実機の台数ではありません。** Shodan の検索に一致したサービス（バナー）の件数です。
- **おとり（ハニーポット）を含みます。** 2026年11月4日以降、一部の国で実機の画面を複製したと見られるサービスが急増しました。件数の増減を、そのまま露出の増減と読まないでください。読み方は、リポジトリ直下の [README](../README.md#結果の読み方) を参照してください。
- **露出していることは、脆弱であることや侵害されたことを意味しません。**
- 期間の条件（`after:`）は、計測日（2026-11-07）から数えています。

## 伏せた情報

`sanitize_for_publication.py` と同じ処理で、次の情報を取り除いています。

| 区分 | 扱い | 理由 |
|---|---|---|
| 事業者名（org・isp）、ASN | 削除 | 露出している店舗や事業者、おとりの運用者を特定できるため |
| 証明書の CN・発行者・フィンガープリント・シリアル | 削除 | 店舗を推定できるホスト名を含むため |
| HTML ハッシュ、ファビコンハッシュ | 削除 | 実機とおとりで共通し、実機を探す目印になるため |
| ページタイトル | 製品名だけを残し、それ以外は `(other titles, redacted)` にまとめた | 店舗名を含むものがあるため |
| クエリ文字列中の HTML ハッシュ | `<REDACTED>` に置き換えた | 同上 |

集中度（`top3_share`、上位3つの値が全体に占める割合）は残しています。値そのものは含みません。

加工前のデータは公開していません。

## 記事の計測と、現在のスクリプトとの違い

- `surge_breakdown` の計測では、タグの件数を `(tag:honeypot OR tag:cloud)` で数えようとして、Shodan に受け付けられませんでした。該当する結果（`*_new_tagged`・`all_tagged_new`）は、エラーとして記録されています。現在の `surge_breakdown.py` は、タグごとに分けて数えるよう修正済みです。
- `exposure_count` の計測のクエリは、現在の `exposure_count.py` を既定の設定で実行したときと同じです（期間は実行日から数えるため、日付は変わります）。
